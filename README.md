# 🏥 MediCare - Medical Appointment Booking Platform

MediCare is a modern, responsive medical appointment booking web application built using **React**, **Vite**, **Bootstrap**, and **Redux Toolkit**.

---
 
 
---

## ✨ Key Features
- 🔍 **Interactive Search**: Search doctors by name, specialty, or location.
- 🩺 **Specialties Exploration**: Browse medical specialties with dedicated icons and doctor counts.
- 👨‍⚕️ **Popular Doctors Showcase**: View top-rated doctors with real-time ratings, location details, and direct booking triggers.
- 📱 **Fully Responsive Layout**: Built with custom CSS and Bootstrap grid for seamless layout across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack & Tools
- **Frontend**: React.js, React Router v6
- **Styling**: Bootstrap 5, Custom CSS3, Flexbox Grid
- **Icons**: React Icons (`react-icons`)
- **State Management**: Redux Toolkit *(Integrated)*
- **Build Tool**: Vite
